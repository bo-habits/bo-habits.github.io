# Сторінка посилань Бо

Статичний сайт для GitHub Pages на домені `bohabit.app` (Namecheap: A-записи GitHub Pages, `www` → `bo-habits.github.io`; `CNAME` у корені — не видаляти; `bo-habits.github.io` переадресовує сюди): сторінка застосунку і посилання на Сад як звичайні https-адреси. Стиль — брендбук «Місто» (Figma «Бо — Брендбук»): `site.css` (токени, кнопки), основа — спокійна `#F6F5F2` (режим «Спокійно»), акцент — галька: сланець `#5B6152`, кнопка з камінцем вугільної гальки; без фіолетових градієнтів, підписів капсом над розділами, появи під час прокрутки й однакових карток, шрифти Unbounded і Onest локально в `fonts/` (підмножина кирилиці й латиниці, OFL), без сторонніх запитів.

- `index.html` — головна: Бо розповідає про себе репліками, «вежка не падає», можливості з екранами (`img/screens/` — кадри 2× з «Дизайн · усі вікна»), дані, питання. Пози Бо — `img/bo/` (обрізані з `Resources/Mascot`, у темній темі інвертуються).

- `.well-known/apple-app-site-association` — Universal Links: `/g/*` відкриває застосунок Бо (`P3Y9NB5P78.com.maxb.bo`).
- `privacy/`, `terms/`, `support/` — політика конфіденційності, умови використання й підтримка (той самий `site.css`); на них посилаються застосунок («Я» → налаштування) і App Store Connect.
- `404.html` — для `/g/<id>` і `/g/d#…`, якщо Бо не встановлено: пояснення й кнопка «Відкрити в Бо» (`zvychky://…`); будь-яка інша невідома адреса веде на головну.

Жодних даних тут немає й нічого не обробляється. Публікується в репозиторій `bo-habits/bo-habits.github.io` (організація `bo-habits`) (гілка `main`, корінь).
